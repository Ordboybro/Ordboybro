## 🚀 Featured projects

### 🎨 OrdPaint
**Desktop raster graphics editor** built with Python + PySide6 / Qt 6.

- Layer system and blend modes
- Selection and transforms
- Brush / eraser / fill / shapes
- Undo / Redo and transactions
- Autosave and crash recovery
- Native `.ordpaint` project format
- Automated tests, linting and Windows packaging

**Stack:** Python · PySide6 · Qt 6 · pytest · Ruff · PyInstaller

[Repository](https://github.com/Ordboybro/OrdPaint)

---

### ☁️ OrdCloud
**Local-first cloud-drive style file manager for Windows.**

- Sandboxed filesystem operations
- Search, favorites and recent files
- Drag & drop and keyboard shortcuts
- Storage analytics and quotas
- Safe deletion and atomic copy operations
- PySide6 desktop architecture with automated tests

**Stack:** Python · PySide6 · Qt · unittest · GitHub Actions

[Repository](https://github.com/Ordboybro/OrdCloud)

---

### 😀 EmojiTasks
**Gamified task manager** where tasks become XP, levels, streaks and achievements.

- XP and level progression
- Daily streaks and achievements
- Search, filters and sorting
- Deadlines and overdue detection
- Native Canvas statistics
- Versioned local storage with migration
- Responsive and accessible UI

**Stack:** HTML · CSS · Vanilla JavaScript

[Live demo / repository](https://github.com/Ordboybro/EmojiTasks)

### 🔐 EmojiPass
**Privacy-first password generator** that runs entirely in the browser.

- Web Crypto API for secure randomness
- Custom character categories and emoji mode
- Entropy estimate and strength indicator
- Clipboard support and session history
- Local settings with no backend
- Accessibility and reduced-motion support

**Stack:** HTML · CSS · Vanilla JavaScript · Web Crypto API

[Repository](https://github.com/Ordboybro/EmojiPass)
